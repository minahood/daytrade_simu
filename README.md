# デイトレードシミュレーター

東証プライム主要 20 銘柄を対象にした日本株デイトレードシミュレーターです。
Yahoo Finance / stooq.com から実際の株価データを取得し、1分足チャートで売買練習ができます。

---

## 起動方法

### 安定版（推奨）― ローカルプロキシサーバーを使う

```bash
python3 server.py
```

起動後、ブラウザで以下を開いてください。

```
http://localhost:8765/index.html
```

サーバー経由でデータを取得するため、CORS 制限やレート制限の影響を受けず安定して動作します。

### 簡易版 ― HTML ファイルを直接開く

`index.html` をブラウザで直接開くだけで使用できます。
ただし公開 CORS プロキシ経由でデータを取得するため、混雑時にエラーが発生することがあります。

## 使い方

### 1. データを読み込む

1. **日付指定**（省略可）: 日付ピッカーで過去の取引日を指定。空欄にすると最新の取引日データを取得します。
2. **「データ読込」ボタン**をクリック。
3. 銘柄は 20 銘柄の中からランダムで選ばれます。
4. ステータス欄にデータの取得元（Yahoo Finance / stooq.com / キャッシュ）と、実データ or 合成データかが表示されます。

> **土日・祝日・年末年始は東証が休場**のためデータがありません。取引日を指定してください。

---

### 2. シミュレーションを操作する

| ボタン | 説明 |
|--------|------|
| **▶ 開始** | シミュレーションを開始します（09:00 から） |
| **⏸ 一時停止** | 任意の時点で一時停止できます |
| **⏩ 早送り** | 1秒＝5分のペースで進めます（通常は 1秒＝1分） |
| **↺ リセット** | 09:00 に巻き戻します（ポジション・損益もリセット。データは保持） |

シミュレーションは **15:30（大引け）** に自動停止します。

---

### 3. 売買する

シミュレーション実行中に売買できます（一時停止中は不可）。

| ボタン | 操作 |
|--------|------|
| **買い（緑）** | ロングポジションを建てる / ショートポジションを返済する |
| **売り（赤）** | ショートポジションを建てる / ロングポジションを返済する |

- 1回の操作で **100株**ずつ増減します。
- 同じ方向に複数回押すとポジションを積み増しできます（平均取得単価が更新されます）。
- 保有ポジションを超える枚数を反対方向に売買すると、**自動でドテン**（反転）します。

---

### 4. 損益を確認する

| 項目 | 説明 |
|------|------|
| **評価損益** | 現在保有中のポジションの含み損益 |
| **確定損益（本日合計）** | 本日クローズした取引の損益合計 |
| **総損益（評価＋確定）** | 評価損益＋確定損益の合計 |

> 初期資金は **1,000万円** です。

---

### 5. ポジション情報・約定履歴

- **ポジション情報パネル**: 現在の方向（ロング/ショート/フラット）・数量・平均取得単価・概算コストを表示。
- **約定履歴**: 直近の売買を時刻・方向・数量・約定値・損益の順に表示します（最大 20件）。

## データソースについて

| ソース | 用途 |
|--------|------|
| Yahoo Finance (query1/query2) | 日足 OHLC・1分足リアルデータ |
| stooq.com | 日足 OHLC のバックアップ |
| 合成データ | 1分足の取得に失敗した場合、日足 OHLC から自動生成 |

取得したデータはブラウザの `localStorage` にキャッシュされます。

| データ種別 | キャッシュ期間 |
|-----------|--------------|
| 日足（最新） | 24時間 |
| 日足（過去の指定日） | 7日間 |
| 1分足（最新） | 24時間 |
| 1分足（過去の指定日） | 15日間 |
